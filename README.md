# PLP Python Week 4 Assignment - Control Flow

This repository contains 3 Python programs demonstrating control flow and decision making.

## Files
1. grade_classifier.py - Classifies scores into grades A-F
2. eligibility_checker.py - Checks eligibility based on age and parental consent
3. atm_menu.py - Simple ATM simulation with PIN check and withdrawal

## How to Run
python grade_classifier.py
python eligibility_checker.py
python atm_menu.py
